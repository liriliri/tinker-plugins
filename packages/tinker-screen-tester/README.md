# tinker-screen-tester

A screen tester plugin for [TINKER](https://github.com/liriliri/tinker), with fullscreen solid colors and patterns for dead pixels, backlight bleed, and banding.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-screen-tester/screenshot.png)

## Features

- **8 Test Patterns** covering white / RGB / black, light bleed, gray ramp, and checkerboard
- **Fullscreen Mode** for accurate dead-pixel and bleed inspection
- **Live Preview** cycling through all patterns before you start
- **Simple Controls** — ← → to switch, click / right-click, Esc to exit, H for hint

## Installation

Play directly in [browser](https://tinker.liriliri.io/plugins/screen-tester), or install via TINKER: download from `https://tinker.liriliri.io/`, then run `npm i -g tinker-screen-tester`.

## Usage

1. Open the plugin and check the preview pane for the available patterns
2. Click **Start Test** to enter fullscreen
3. Use ← / → (or click / right-click) to step through patterns
4. Press **H** to show the current pattern name, **Esc** to exit fullscreen
