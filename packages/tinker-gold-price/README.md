# tinker-gold-price

A gold price plugin for [TINKER](https://github.com/liriliri/tinker), showing Shanghai Gold Exchange Au9999 quotes with intraday chart.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-gold-price/screenshot.png)

## Features

- **Au9999 Quote** with latest price, change, and OHLC
- **Intraday Chart** for the current trading session
- **Auto Refresh** every 60 seconds, plus manual refresh

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-gold-price`.

## Usage

1. Open the plugin to view the latest Au9999 price and intraday chart
2. Click "Refresh" to reload quote and chart data

## Data Source

Powered by [East Money](https://www.eastmoney.com/) market data. Data is for reference only and is not investment advice.
