# tinker-game-music

A video game MIDI music plugin for [TINKER](https://github.com/liriliri/tinker), supporting browsing, search, in-app preview, and download from VGMusic.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-game-music/screenshot.png)

## Features

- **Browse by System** across consoles and computers
- **Search** by song title, game, or sequencer
- **MIDI Preview** with play, seek, and stop
- **Save MIDI** to local disk
- **Random Play** within the current filtered list

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-game-music`.

## Usage

1. Pick a system in the left sidebar
2. Expand a game and click a song to preview
3. Use search to filter songs, or Random to pick one
4. Click Save to download the current MIDI file

## Data Source

MIDI files are sourced from [VGMusic.com](https://www.vgmusic.com/).
