# tinker-nes

A NES emulator plugin for [TINKER](https://github.com/liriliri/tinker), supporting ROM loading with keyboard controls and fullscreen playback.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-nes/screenshot.png)

## Features

- **NES Emulation** with full keyboard controls
- **ROM Loading** via file picker or drag and drop
- **Pause / Resume** and **Reset** support
- **Mute / Unmute** audio toggle
- **Fullscreen** mode

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-nes`.

## Usage

1. Click **OPEN ROM** to load a `.nes` file, or drag and drop it onto the screen
2. Use keyboard arrow keys and buttons to play
3. Click **PAUSE** / **RESUME** to pause or continue the game
4. Click **RESET** to restart the current ROM
5. Click **MUTE** / **UNMUTE** to toggle audio
6. Click **FULLSCREEN** to enter fullscreen mode
