# tinker-coding-agent

A coding agent plugin for [TINKER](https://github.com/liriliri/tinker), providing a GUI coding assistant for editing and coding tasks.

## Features

- Chat UI powered by assistant-ui
- Agent loop and tools (read / write / edit / bash) via pi
- Model calls through Tinker `callAI` / `callAIStream`

## Usage

1. Open a workspace folder
2. Select an AI provider and model configured in Tinker
3. Ask the agent to inspect or edit code
