# tinker-stock

Stock data browser for [TINKER](https://github.com/liriliri/tinker), powered by Tencent WeStock data (`westock-data-clawhub`).

## Features

- Search A-share / HK / US symbols
- Watchlist with latest daily snapshots
- Hot stocks, hot ETFs, sector boards, IPO calendar
- Symbol detail: overview, intraday / K-line, fund flow, chips, financials, shareholders, dividends

## Data source

[westock-data-clawhub](https://www.npmjs.com/package/westock-data-clawhub) (Tencent WeStock). Data is for reference only and is not investment advice.
