# tinker-bongo-cat

A Bongo Cat desktop pet plugin for [TINKER](https://github.com/liriliri/tinker). The cat drums with your keyboard and follows the mouse pointer.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-bongo-cat/screenshot.png)

## Features

- **Keyboard drumming** — left hand and key highlights for WASD, QER, Space, and 1–7
- **Mouse follow** — right arm and mouse cursor track the pointer across the screen
- **Button overlays** — left / right / side mouse clicks light up on the mouse
- **Random faces** — click the cat’s head for a short expression
- **Floating window** — pop out an always-on-top companion; drag to move; size slider; restores after reopen

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-bongo-cat`.

## Usage

1. Open the plugin and type or move the mouse — the cat reacts in the main window
2. Drag the **Size** slider to scale the scene
3. Click **Pop out** for an always-on-top floating window (drag to reposition)
4. Click the cat’s head for a random face
5. Close and reopen the plugin while floating — the window restores automatically
