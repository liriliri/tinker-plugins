# tinker-mailbox

A mailbox plugin for [TINKER](https://github.com/liriliri/tinker) with IMAP receive (imapflow) and SMTP send (nodemailer).

## Features

- Add IMAP/SMTP accounts (Gmail, Outlook, QQ, 163, and generic presets)
- Browse folders and recent messages
- Read message text/HTML
- Compose and send plain-text mail

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-mailbox`.
