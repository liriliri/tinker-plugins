# tinker-color-bg

A colorful abstract background generator plugin for [TINKER](https://github.com/liriliri/tinker), powered by [color4bg.js](https://github.com/winterx/color4bg.js).

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-color-bg/screenshot.png)

## Features

- **13 WebGL styles** — aesthetic fluid, ambient light, wavy waves, and more
- **Live preview** with full-bleed animated rendering
- **Color palettes** plus per-color customization
- **Style options** for seed, animation, noise, scale, speed, and more
- **PNG export** at a custom width and height

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-color-bg`.

## Usage

1. Click the style button on the left to pick a background style
2. Choose a palette or edit individual colors on the right
3. Adjust seed, animation, and style-specific options as needed
4. Set export size and click "Export PNG" to save the image
