# tinker-aquarium

A desktop aquarium plugin for [TINKER](https://github.com/liriliri/tinker), rendering a glass tank with real-time water, a procedural reef, and swimming fish.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-aquarium/screenshot.png)

## Features

- **3D glass tank** with orbit camera, powered by [three.js](https://threejs.org/)
- **Interactive water** — drag the surface to make ripples; nearby fish dart away
- **Caustics & refraction** on the sand, glass, reef, and bubbles
- **Fish** — goldfish, angelfish, guppies, and neon tetras, with adjustable counts
- **Procedural reef** of coral, rubble, plants, and glass marbles, regenerated from a seed
- **Dune sand** and bubble columns that change with each reef layout
- **Lighting & views** remembered across sessions

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-aquarium`.

## Usage

1. Orbit the tank with the mouse; drag on the water surface to add ripples
2. Hover the window and click the settings button in the top-right corner
3. Adjust lighting, fish counts, render scale, and reef density, size, and vibrance
4. Click **Regenerate** for a new reef, sand, and bubble layout
