# tinker-aquarium

A desktop aquarium plugin for [TINKER](https://github.com/liriliri/tinker), rendering a glass tank with real-time water and a procedural reef.

## Features

- **3D Glass Tank** with orbit camera, powered by [three.js](https://threejs.org/)
- **Interactive Water** — click and drag the surface to make ripples; ambient drips keep the tank alive
- **Caustics & Refraction** on the sand bed, glass walls, and reef
- **Procedural Reef** of coral, rubble, and plants, regenerated from a seed
- **Reef Settings** for density, size, and vibrance, remembered across sessions

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-aquarium`.

## Usage

1. Orbit the tank with the mouse; drag on the water surface to add ripples
2. Hover the window and click the settings button in the top-right corner
3. Adjust reef density, size, and vibrance
4. Click **Regenerate** for a new layout
