# tinker-trending

A trending hot search plugin for [TINKER](https://github.com/liriliri/tinker), aggregating trending topics from multiple platforms.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-trending/screenshot.png)

## Features

- **Multiple Sources** including Hacker News, GitHub, Zhihu, Weibo, Bilibili, Steam, and more
- **Hottest & Realtime** modes depending on the source
- **Add / Remove / Reorder** sources via the manage dialog
- **Auto Refresh** once per day with manual refresh support
- **Dark Mode** support

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-trending`.

## Usage

1. Browse trending items from each source card
2. Click any item to open it in the browser
3. Click the refresh icon on a card to reload that source
4. Click **+** in the toolbar to add or remove sources
5. Drag cards to reorder them
