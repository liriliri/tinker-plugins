# tinker-radio

Search and play internet radio stations for [TINKER](https://github.com/liriliri/tinker). Station data comes from [Radio Browser](https://www.radio-browser.info/).

## Installation

Play directly in [browser](https://tinker.liriliri.io/plugins/radio), or install via TINKER: download from `https://tinker.liriliri.io/`, then run `npm i -g tinker-radio`.
