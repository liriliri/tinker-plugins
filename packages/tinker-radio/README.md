# tinker-radio

Search and play internet radio stations for [TINKER](https://github.com/liriliri/tinker). Stations are drawn on a night globe.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-radio/screenshot.png)

## Features

- **Night globe** of stations, powered by WebGL — drag to turn, scroll to zoom, click a point to play
- **Language and genre filters**, remembered the next time you open the plugin
- **Search** by station name, place, or language
- **Saved stations**
- **Playback** with previous, next, random, volume, and mute
- **Level meter** while a station is playing

## Installation

Play directly in [browser](https://tinker.liriliri.io/plugins/radio), or install via TINKER: download from `https://tinker.liriliri.io/`, then run `npm i -g tinker-radio`.

## Usage

1. Press play for a random station, or click a point on the globe
2. Filter by language or genre, or search from the top right
3. Save a station with the heart, and open it again from the saved list
4. Use Space to play or pause, and the arrow keys for the previous or next station

## Data Source

Station data comes from [Radio Browser](https://www.radio-browser.info/).
