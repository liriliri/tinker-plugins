# tinker-lan-share

A LAN file share plugin for [TINKER](https://github.com/liriliri/tinker), hosting an HTTP service so devices on the same network can browse, upload, and download shared files.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-lan-share/screenshot.png)

## Features

- **LAN HTTP server** — share files over the local network via browser
- **Upload & download** files or folders from any device on the same Wi-Fi
- **Live sync** — file list updates across clients when changes happen
- **QR code** — open with `tinker-qrcode` for quick phone access

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-lan-share`.

## Usage

1. Open the plugin and start the server
2. Open the shown URL (or QR code) on another device
3. Upload, browse, and download shared files in the browser
