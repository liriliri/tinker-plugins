# tinker-weather

A weather plugin for [TINKER](https://github.com/liriliri/tinker), providing real-time weather information and forecasts.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-weather/screenshot.png)

## Features

- **Real-time Weather** with temperature, humidity, wind, and UV index
- **3-Day Forecast** with temperature range bars
- **City Search** with pinyin support for Chinese input
- **Recent Cities** for quick switching

## Installation

Play directly in [browser](https://tinker.liriliri.io/plugins/weather), or install via TINKER: download from `https://tinker.liriliri.io/`, then run `npm i -g tinker-weather`.

## Usage

1. Search for a city in the sidebar
2. View current weather and 3-day forecast
3. Switch between recent cities
