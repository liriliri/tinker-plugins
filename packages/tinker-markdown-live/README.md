# tinker-markdown-live

A WYSIWYG markdown editor plugin for [TINKER](https://github.com/liriliri/tinker), powered by Milkdown.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-markdown-live/screenshot.png)

## Features

- **WYSIWYG editing** with live markdown preview
- **Slash commands** for quick block insertion
- **Rich content** support including tables, code blocks, LaTeX, and images
- **Dark mode** support
- **File operations** for opening and saving markdown files
- **i18n** support for English and Chinese

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-markdown-live`.

## Usage

1. Start typing in the editor or use `/` slash commands to insert blocks
2. Click "Open" to load an existing markdown file
3. Click "Save" to save your work
4. Click "New" to create a blank document
