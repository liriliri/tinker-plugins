# tinker-map

A map plugin for [TINKER](https://github.com/liriliri/tinker), providing an interactive map interface with location browsing and search.

![Screenshot](https://raw.githubusercontent.com/liriliri/tinker-plugins/master/packages/tinker-map/screenshot.png)

## Features

- **Interactive Map** powered by Leaflet
- **Location Search** by name or description
- **Location List** sidebar with click-to-focus

## Installation

Download and install TINKER from `https://tinker.liriliri.io/`, then run `npm i -g tinker-map`.

## Usage

1. Browse locations on the map or in the sidebar list
2. Search for locations using keywords
3. Click a location to focus the map on it
